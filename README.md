# beginner-cpp-auto

# 🔤 C++ Auto Variable Demo

This beginner-friendly C++ program demonstrates how to use the **`auto` keyword** to automatically determine the data type of variables.

## 🚀 What This Program Does
- 👤 Declares an integer variable (`age`) using `auto`
- 🏆 Declares a character variable (`grade`) using `auto`
- 🖥️ Displays the values on the console
- 📚 Helps beginners understand automatic type deduction in C++

## 💻 Technologies Used
- C++
- Standard Library (`iostream`)

## 📖 Concepts Covered
- `auto` keyword
- Integer (`int`) data type
- Character (`char`) data type
- Variable declaration and initialization
- `cout` and `endl`
- `main()` function
- Basic C++ syntax

## 🎯 Output

```
Age = 18
Grade = A
```

## 🌟 Learning Outcome
By completing this program, beginners will understand:
- ✅ How the `auto` keyword works
- ✅ Automatic type deduction in C++
- ✅ Storing different types of data
- ✅ Displaying output using `cout`

- Practice with the `auto` keyword
